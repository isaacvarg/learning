# Morse code Resources

## Knowledge

- [Standard: ITU-R M.1677-1, International Morse code](https://www.itu.int/rec/R-REC-M.1677-1-200910-I/)
  The official definition of every character, prosign and the 1-3-7 timing ratios. Use for: what a character *is*; settle any doubt about a code or spacing.
- [Article: "Morse Code Timing" (morsecode.world)](https://morsecode.world/international/timing.html)
  Clear, interactive explanation of the PARIS word, dit length, Farnsworth and Wordsworth spacing. Use for: explaining wpm, character vs effective speed, timing errors when sending.
- [Paper: "A standard for Morse timing using the Farnsworth technique" (ARRL)](http://www.arrl.org/files/file/Technology/x9004008.pdf)
  The ARRL's formula for stretched character spacing. Use for: setting effective wpm below character wpm correctly.
- [Book: _The Art and Skill of Radio-Telegraphy_ by William Pierpont, N0HFF](https://archive.org/details/art-and-skill-of-radio-telegraphy)
  The classic, free manual on learning code by sound, the Koch method, head copy and building speed. Use for: learning method, plateaus, why to avoid counting dots, sending technique. The single best book to read alongside this course.
- [Trainer: Learn CW Online (LCWO)](https://lcwo.net/)
  Free web trainer with a 40-lesson Koch course, word and callsign training and plain-text practice. Use for: the Koch character order this curriculum follows; extra copy practice between sessions.
- [Software: G4FON Koch trainer](https://www.g4fon.net/)
  Ray Goff's long-standing Koch-method trainer. Use for: background on Koch at full character speed; an offline alternative to LCWO.
- [Audio: Morse Code Ninja](https://morsecode.ninja/)
  Huge free library of practice audio (common words, phrases, plain text) at graded speeds. Use for: unit 2 whole-word recognition and unit 3 plain-text copy at 15-25 wpm.
- [Audio: ARRL code practice files and W1AW schedule](https://www.arrl.org/code-practice-files)
  Graded practice text from 5 to 40 wpm, with the text to check against ([schedule](https://www.arrl.org/w1aw-operating-schedule)). Use for: unit 3 copy tests at 20 wpm with a known answer key.
- [Guide: "Learning Morse Code" (ARRL)](https://www.arrl.org/learning-morse-code)
  Overview of learning methods and tools. Use for: pointers when the learner wants alternatives.

## Wisdom (Communities)

- [r/morse](https://www.reddit.com/r/morse/)
  Active subreddit of Morse learners at every level. Use for: plateau advice, sharing progress, practice partners.
- [Long Island CW Club](https://longislandcwclub.org/)
  Large online club running free Zoom classes for every level, open to non-hams. Use for: live sending feedback from other people.
- [CWops CW Academy](https://cwops.org/cw-academy/)
  Respected structured course with live advisors, aimed at radio operators. Use for: later, if the learner opens the door to on-air CW.
